# @lotmark/stats

The ISO Guide 35 computation engine. Pure functions, no I/O, no database.

| Module | Produces | Guide 35 role |
|---|---|---|
| `homogeneity.ts` | `u(bb)` via one-way ANOVA over units | Between-unit inhomogeneity |
| `stability.ts` | `u(lts)` from SE(slope) × shelf life | Long-term stability |
| `characterisation.ts` | `u(char)` **and the assigned value** | Interlaboratory consensus |
| `budget.ts` | `u_c` (root sum square), `U = k·u_c` | Combined & expanded uncertainty |

## Why the numbers must not move

`src/__tests__/prototype-golden.json` was generated by executing the original
functions from `docs/artefacts/lotmark-app.html` against its own seed data. The
golden tests assert **exact** float equality — not approximate. A certificate
states an assigned value and an expanded uncertainty; if this package's output
drifts, every certificate computed under the old code becomes unreproducible,
which is an ISO 17034 and 21 CFR Part 11 problem, not a rounding nuisance.

Regenerating the fixture is a deliberate, documented decision.

## Hardening applied over the prototype

The prototype was a demonstration and took shortcuts this package refuses:

- **Unbalanced designs** — it read the replicate count off the first unit and
  would mis-analyse ragged data silently. Now rejected with `UNBALANCED_DESIGN`.
- **Two-point stability** — residual variance divides by `n-2`, so two points
  gave a division by zero and a meaningless zero uncertainty. Now requires 3+.
- **Non-finite measurements** — now rejected rather than propagating `NaN` into
  a published uncertainty.
- **Zero time variation** — all timepoints identical gave `0/0`. Now rejected.

Behaviour for valid, balanced input is unchanged and test-locked.

## Known limitation, deliberately left open

`consensus()` is an unweighted mean with no outlier treatment. Guide 35 also
permits robust estimators (Algorithm A, Q-Hampel) and weighting by each
laboratory's reported uncertainty. Introducing one changes how values are
assigned, so it must be a versioned choice recorded on the study — not a silent
improvement. See the note in `characterisation.ts`.
