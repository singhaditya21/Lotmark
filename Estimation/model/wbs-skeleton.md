# Work-package skeleton — quantity drivers only

Effort numbers are deliberately absent here. This file names, for every package,
WHAT ITS EFFORT IS A FUNCTION OF, so that when the Phase 2 inventory lands the
model is re-run rather than re-argued. A package whose driver is "elapsed
duration" moves when the schedule moves, not when the page count does.

## The four quantities everything hangs on

1. **Surviving HTML page count** after triage — drives 2.6, 2.8, 3.4, 3.9.
2. **PDF count and disposition** — drives 2.7, 3.7, and the bilingual-PDF gap.
3. **Distinct template count** — drives 3.2 and most of 3.9. Accessibility
   effort tracks templates far more than pages.
4. **The applications decision** (e-services, shop, PvPI, iponline) — this is
   not a quantity but a boundary, and it is the largest single swing.
